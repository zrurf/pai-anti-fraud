# 黄金测试集构建规范与 LLM 生成 Prompt

## 目的与定位

黄金测试集（`data/golden_test_set.jsonl`）是**人工审核**的校园风格评估集，用于检验模型在目标场景（校园消息）上的表现与域偏移程度——正式训练池来自公开数据集（短信/通话转写/受害人笔录/邮件），与"学生日常收到的 QQ/微信/短信消息"存在文体差异。

原则：

1. **不进入训练**：构建完成后运行 `python -m scripts.validate_golden_set.py`，其中的泄漏检查会与 train/val/test 逐条比对；
2. **规模**：200 条，四类均衡（每类 50 条）；
3. **难度**：重点构造**难负例**——"看起来像诈骗的正常消息"与"看起来正常的推销/钓鱼"，这是黄金集区别于随机抽样的核心价值；
4. **流程**：LLM 生成（用本文 prompt）→ 人工逐条审核修改 → 校验脚本通过 → 冻结。

## 文件格式

JSONL，每行一条：

```json
{"text": "消息正文", "label": 0, "subtype": "official_notice"}
```

- `label`：0=正常，1=推销，2=刷单，3=钓鱼（与训练池一致）；
- `subtype`：细类型标签（英文短横线命名），用于分组分析，见下表。

| label | subtype 建议 | 说明 |
| :--- | :--- | :--- |
| 0 正常 | course_notice / club_activity / admin_notice / teacher_msg / delivery_logistics / legit_promo / classmate_chat | `legit_promo` 是关键难负例：商家/平台的**合法**推广（可退订、无链接诱导、无紧迫话术） |
| 1 推销 | product_promo / training_course / subscription_push / agent_recruit | 商业推广与话术推销，含校园场景（考研辅导、驾校、电话卡） |
| 2 刷单 | rebate_parttime / order_advance / task_platform | 刷单返利话术：小额返利垫付、刷信誉、做任务 |
| 3 钓鱼 | impersonate_official / impersonate_teacher / phishing_link / account_verify / scholarship_bait | 冒充（公检法/老师/平台客服）、诱导点击、账号验证、奖助学金诱饵 |

## 使用方法

把下面"生成 Prompt"整段复制给 LLM（建议一次生成 50–60 条，分 4 批并每批指定不同的 `scenario_seed`，避免同质化），将输出保存为 JSONL 后**逐条人工审核**（重点：真实性、标签正确性、是否像真实校园消息而非 LLM 腔），再运行校验脚本。

---

## 生成 Prompt（复制以下全部内容使用）

```text
你是一个中文语料构造专家。请为"校园网络诈骗文本四分类器"生成一组高质量的黄金测试样本。

【任务】生成 50 条真实的大学校园场景消息，JSONL 格式，每行一条：
{"text": "<消息正文>", "label": <0|1|2|3>, "subtype": "<见类型表>"}

【类别定义】
0=正常：学生/老师/学校之间正常往来的消息；
1=推销：商业推广（商品、培训、订阅、代理招募），目的是让你买东西或注册；
2=刷单：刷单返利兼职话术（小额返利取得信任→大额垫付、连单、卡单），目的是骗垫付资金；
3=钓鱼：冒充身份（公检法、老师、辅导员、平台客服、同学）或诱导点击链接/泄露信息（验证码、账号、点击领取），目的是骗取信息或资金。

【本批类型配额（必须严格遵守）】
- 正常 14 条，其中至少 5 条是"难负例"：
  a) 合法商家的正常推广（有明确退订方式、无紧迫感、无陌生链接，例如话费积分兑换、官方会员日）；
  b) 内容严肃真实的官方通知（缴费提醒、图书馆过期通知、教务处选课通知——语气紧迫但渠道正规，不含索要隐私信息）；
- 推销 12 条：含校园高频场景（考研/考证培训、驾校、校园电话卡、健身卡、代订机票）；
- 刷单 12 条：覆盖话术演化各阶段（首单小额返现的"香饵"、垫付连单、以"任务未完成"要求继续刷、招募"打字员/点赞员"）；
- 钓鱼 12 条：覆盖冒充辅导员/老师（收取费用、点击填报）、冒充平台客服（会员误开通、快递理赔）、奖助学金/补贴领取、虚假链接与账号验证。

【scenario_seed：本批场景池】（每条消息从这些场景取材，不要遗漏）
<在每次调用时从下面挑选替换 6-8 个：选课系统、期中考试、毕业答辩、宿舍检查、奖学金评定、校园卡充值、快递驿站、社团招新、运动会、图书馆占座、实习推荐、二手交易群、寒假火车票、食堂满意度调查>

【写作要求（非常重要）】
1. 像真实消息，不像 AI 生成的示例：长度 12–120 字为主，允许 1–2 条长消息（转发通知类 150–200 字）；
2. 口语化、有真实细节（具体金额、时间、楼层、QQ 群号格式），金额用"100-500 元"区间的整数；
3. 隐私安全：不使用任何真实姓名、手机号、网址。姓名一律用"王老师/李同学/张导员"，链接写成"https://xxxx.com"或"点击 t.cn/xxxx"，电话写成"138****5678"，QQ/微信号写成"QQ: 88xxxx10"；
4. 话术要符合 2024-2026 年的真实诈骗演化：刷单会提"做任务""垫付""连单卡单"；钓鱼会提"屏幕共享""安全账户""领取助学金需要先验证身份"；推销会提"前 50 名""学长推荐"；
5. 禁止：emoji 堆砌、"亲爱的同学们"式的套话开头、明显的 AI 腔（"在这个数字化时代…"）；正常消息不要故意写错字，诈骗消息允许少量诱导性错别字；
6. 每条消息只属于一个类别，不要在文本里标注类别或解释。

【输出】只输出 JSONL，不要任何解释、前后缀或代码块标记。
```

## 人工审核清单

LLM 输出必须逐条过以下检查，再进入黄金集：

1. **标签正确**：按上面四类定义独立判断一遍，不一致的修改标签或文本；
2. **真实性**：删掉"AI 腔"明显的条目；正常消息尤其要像真人发的；
3. **难负例质量**：`legit_promo` 与严肃官方通知这两类难负例，确认"人眼初看会犹豫"才算合格；
4. **隐私**：确认没有真实姓名/号码/链接残留；
5. **多样性**：同一 subtype 下文本结构不应雷同（同一模板换词的整组删除）。

审核完成后：

```bash
python -m scripts.validate_golden_set.py    # 格式/分布/重复/泄漏检查，通过后方可使用
```

## 使用方式

黄金集只用于评估（域偏移预检、误报率分析），不参与任何训练与模型选择：

```bash
python -m scripts.eval_testset --checkpoint <ckpt> --mode <stage1|stage3> \
    --test data/golden_test_set.jsonl --out results/golden_<模型名>.json
```
