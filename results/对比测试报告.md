# 对比测试报告

测试集：data/processed/test.jsonl（n=28,366，四类：正常 16,485 / 推销 5,327 / 刷单 14 / 钓鱼 6,540）。
所有模型共享同一数据划分与 tokenizer 输入；除特别注明外数字为种子 42 单次训练 + bootstrap 95% 置信区间（1,000 次重采样）。
原始指标 JSON 见 results/*.json；复现命令见 docs/技术文档.md §8。

## 1. 实验设置

- 任务：中文消息四分类（0=正常 / 1=推销 / 2=刷单 / 3=钓鱼）；训练池 327,232 条（正常 160,330 / 推销 53,939 / 刷单 28,492 / 钓鱼 84,471）。
- 类别不平衡处理：全局类别权重（训练集频率倒数）+ 阶段二 WeightedRandomSampler（负责类别约 3 倍过采样）。
- 硬件/软件：RTX 4060 Laptop 8GB；Python 3.14 / torch 2.14+cu130 / transformers 5.14 / peft 0.21。
- 模型选择：各阶段按 val Macro-F1 保留 best checkpoint；test 仅用于最终评估。

按类的关键结论：

1. 四个模型对"正常"类最强（F1 0.92–0.97），该类样本最多、文体分散。
2. 主要误差轴为钓鱼↔推销：MoE 中 941 条钓鱼被误判为推销、485 条反向。
3. 传统基线在刷单类崩溃（NB 完全不预测该类）；两种单头对刷单的 Precision 偏低（0.53–0.56，把大量非刷单误判为刷单），完整系统缓解了该问题（0.87）。
4. 完整系统的推销 Recall（0.8752）高于其余方案，漏报明显减少，代价是 Precision 略降。

## 7. 消融：融合方式（不重训，仅换融合）

| 融合方式 | Accuracy | Macro-F1 | 95% CI | ECE |
| :--- | ---: | ---: | :---: | ---: |
| 门控加权（完整系统） | 0.9110 | 0.8835 | [0.8456, 0.9094] | 0.0105 |
| A1 等权平均 | 0.9105 | 0.8827 | [0.8444, 0.9085] | 0.0094 |
| A2 top-1 硬选择 | 0.8906 | 0.8076 | [0.7539, 0.8465] | 0.0196 |

结论：门控软融合与等权平均在噪声内持平（差 0.0008），两者均显著优于 top-1 硬选择（-7.6 点且校准恶化）。本系统的增益来自多专家互补表示与软融合；路由器当前的价值在软融合机制与可解释性（专家权重/意见可视化），尚未学到显著异于等权的动态权重。路由负载均衡健康：激活比例 f_i=[0.276, 0.152, 0.186, 0.386]，平均门控概率 p_i=[0.264, 0.196, 0.266, 0.274]，无专家塌缩。

阶段二各专家独立最佳 val Macro-F1：推销 0.7816 / 刷单 0.8281 / 钓鱼 0.7886 / 正常 0.8048。刷单专家最高不能归因于其注意力池化——四个专家在层数、数据侧重与类别文体难度上均不同（混杂设计，未做逐项消融）。
